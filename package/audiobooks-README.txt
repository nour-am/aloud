Aloud — Audiobooks Folder
=========================

Copy your DRM-free audiobooks into this folder over USB:

1. Single-file audiobooks:
   - Drop `.m4b`, `.m4a`, `.mp3`, `.ogg`, `.opus`, or `.flac` files directly
     into this `audiobooks/` folder. Embedded chapters and cover art are
     detected automatically.

2. Multi-file chapter folders:
   - Drop a folder per book (for example: `Author - Book Title/`) containing
     chapter `.mp3` / `.m4a` / `.opus` / `.flac` files.
   - Files are ordered using natural sort (`01`, `02`, ..., `10`).
   - Optional: place `cover.jpg` or `cover.png` inside the book folder if the
     audio files do not have embedded cover art.

Then open "Aloud" from your Kindle library (or from KUAL).

Titles in Arabic, Chinese or Japanese show as "?" until you add a font pack:
download aloud-fonts-arabic or aloud-fonts-chinese-japanese from the Aloud
release page and unzip it onto the Kindle the same way as Aloud itself.
